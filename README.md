Developer Portfolio
A personal portfolio website built with HTML, CSS and JavaScript. It shows my skills and projects, and lists my public repositories automatically using the GitHub API.

Features
  Dark, clean design
  Sections: About, Skills, Projects, GitHub
  Smooth scrolling and sticky navigation bar
  Repositories loaded live from the GitHub API

Built With
   HTML5
   CSS3
   JavaScript (ES6)
   GitHub REST API
   
Files
  index.html   - page content
  style.css    - styling
  script.js    - GitHub API code
  
How to Run
  1. Download or clone this repository:
    git clone https://github.com/tsiyonerku-rgb/final-project.git
  2. Open index.html in your browser.

Show Your Own Repositories
  Change the username at the top of script.js:
js:
 const GITHUB_USERNAME = "your-username";
